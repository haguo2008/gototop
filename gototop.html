扇形进度环的设计

右下角的「回到顶部」按钮采用圆锥渐变（conic-gradient）实现扇形进度指示。从12点钟方向开始，顺时针填充环形区域。

页面滚动百分比直接映射为扇形的角度：0% → 扇形为空，100% → 完整闭合圆环。

💡 核心机制：使用 CSS 自定义属性 --progress 动态控制 conic-gradient 的颜色停止位置，JavaScript 监听滚动事件实时更新该变量。
conic-gradient CSS Mask 环形进度 扇形填充

什么是圆锥渐变？

conic-gradient 是 CSS 中的一种渐变类型，颜色围绕中心点按角度分布，非常适合创建饼图、扇形和环形进度指示器。

在本实现中，from -90deg 让渐变从顶部（12点钟位置）开始，颜色段覆盖的角度由滚动进度百分比决定。环形效果通过 mask 属性挖空中心区域来实现。

🎯 关键代码：
background: conic-gradient(from -90deg, #ff5e62 0% calc(var(--progress) * 1%), transparent calc(var(--progress) * 1%) 100%);

性能优化

滚动事件使用 requestAnimationFrame 进行节流，避免频繁触发重排。CSS 变量更新仅影响单个元素的背景样式，不会引起大规模的回流（reflow）。

同时使用了 will-change 提示和 passive 事件监听器，确保在移动设备上也能流畅运行。

requestAnimationFrame passive事件 无回流 60fps

交互细节

当页面滚动到顶部附近（≤80px）时，按钮会自动淡出隐藏，避免遮挡内容。向下滚动后按钮平滑显现，扇形进度同步更新。

点击按钮触发 scrollTo({top: 0, behavior: 'smooth'}) 平滑回到顶部。悬停时按钮放大、箭头弹跳、显示百分比提示。

到达页面底部（100%）时，扇形完全闭合形成完整彩色圆环，并伴有微妙的阴影变化提示用户已到达终点。

平滑滚动 悬停反馈 自动隐藏 闭合动画

无障碍与响应式

按钮具备完整的键盘可访问性（支持 Enter/Space 键触发），设置了明确的 aria-label 属性。在移动端，按钮尺寸自动适配不同屏幕，最小支持 320px 宽度。

同时尊重用户的减少动画偏好（prefers-reduced-motion），在系统设置中开启该选项时会禁用弹跳等装饰性动画。

WCAG 2.1 键盘导航 响应式 reduced-motion

CSS 自定义属性驱动样式更新，JavaScript 仅负责滚动监听和进度计算，职责分离明确。

扇形之美

扇形是圆的一部分，由两条半径和一段弧围成。在这个交互组件中，扇形的圆心角与页面滚动进度成正比——这是信息可视化中「进度隐喻」的经典应用。

从视觉心理学角度，圆形进度指示器比线性进度条更具吸引力，因为人对「闭合圆形」有天然的完形倾向——看到未闭合的环时，潜意识会期待它完成。

接近终点的微妙变化

当滚动进度超过 95% 时，进度环会添加一个额外的 CSS 类 full-circle，使阴影从默认的灰色转变为带有环颜色（珊瑚红）的柔和光晕，暗示终点即将到来。

到达 100% 时扇形完全闭合，与环的起始点无缝衔接，形成一个完美、饱满的彩色圆环——这就是「闭圆」的含义。
